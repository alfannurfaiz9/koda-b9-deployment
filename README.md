WEEKLY 7
1. Linux kernel adalah inti dari sistem operasi linux yang berfungsi sebagai jembatan penghubung antara software dengan hardware, memiliki fungsi utama untuk manajemen memori, manajemen proses, manajemen perangkat, keamanan sistem. Sedangkan distro linux adalah versi atau varian dari sebuah sistem operasi linux yang dibangun diatas kernel linux serta dilengkapi berbagai komponen perangkat lunak seperti package manager, desktop environment dan aplikasi pendukung lainnya.
2. Linux FHS adalah sebuah standar yang mendefinisikan struktur, penataan folder serta letak file dalam sistem operasi berbasis linux, contoh kegunaannya: memudahkan pencarian serta pengelolaan folder dan file.
3. Sistem permission dan owner berfungsi untuk mengatur izin akses dan kepemilikan file serta direktori demi menjaga keamanan dan aksesibilitas di dalam sistem Linux.
4. Bash adalah versi penyempurnaan dari sh yang ditambahkan fitur fitur modern seperti history, dan tab completion. Sh adalah shell unix asli yang paling basic dan fiturnya sangat terbatas. Sedangkan shell lain menawarkan fitur berbeda beda tergantung pengembangnya, Seperti zsh yang menawarkan fitur kustomisasi visual pada shell terminal.
5. SSH memiliki 3 prinsip utama yaitu:
	-  Symmetric Encryption : adalah penggunaan satu private key yang sama (kunci sesi) oleh klien dan server untuk mengenkripsi serta mendekripsi seluruh data yang dikirimkan selama sesi berlangsung 
	- Asymmetric Encryption : adalah proses autentikasi yang aman serta pertukaran kunci sesi, memanfaatkan sepasang kunci kriptografi yang saling terkait yaitu public key dan private key 
	- Hashing : adalah proses mengubah data menjadi nilai unik berukuran tetap untuk menjaga integritas pesan
6. Perbedaan antara HTTP dan HTTPS: HTTP mengirimkan data menggunakan plain text (teks polos) sehingga data tidak aman dan mudah disadap atau di ubah di tengah jalan, Sedangkan HTTPS enggunakan lapisan enkripsi (SSL/TLS). Data diacak sehingga tidak bisa dibaca oleh pihak ketiga dan menjadikannya lebih aman.
7. Docker OCI Compliance Standard adalah standar untuk memastikan bahwa container image dan container runtime buatan Docker mengikuti spesifikasi yang ditetapkan oleh Open Container Initiative (OCI).
8. Perbedaan antara Container dan VM: VM melakukan virtualisasi pada tingkat perangkat keras (hardware), sedangkan Container melakukan virtualisasi pada tingkat sistem operasi (OS kernel).
9. Image layer pada docker adalah tumpukan lapisan sistem file (file system layers) yang bersifat read-only dan saling bertumpuk untuk membentuk sebuah Docker Image. Manfaatnya untuk mengoptimalkan penyimpanan dan mempercepat proses build.
10. Docker volume digunakan untuk menyimpan data secara permanen di host OS luar kontainer serta agar bisa berbagi data antar container. Contoh penggunaan: Misalnya untuk menyimpan data yang diupload oleh user agar data tersebut tidak hilang atau agar bisa diakses oleh container lain. Docker network digunakan untuk komunikasi antar container serta menghubungkan 	port di dalam container ke port host agar aplikasi bisa diakses pengguna lewat browser
11. Web Server adalah perangkat lunak (software) atau sistem yang bertugas menyimpan, memproses, dan menyajikan konten situs web kepada pengguna melalui protokol HTTP atau HTTPS. Digunakan untuk menyajikan Konten Statis & Dinamis serta menerima dan memproses request. Reverse Proxy adalah perantara (server) yang berada di depan satu atau beberapa web server/aplikasi. Saat pengguna mengirimkan request, pengguna tidak langsung terhubung ke server utama, melainkan diterima dulu oleh reverse proxy, baru kemudian diteruskan ke server aplikasi di belakangnya. Digunakan untuk:
- Load Balancing : Membagikan trafic pengunjung secara merata ke beberapa server agar server tidak tumbang saat pengunjung melonjak
- Meningkatkan Keamanan : menyembunyikan alamat IP asli dari server backend
- Caching : menyimpan salinan konten yang sering diakses. Jika ada pengguna lain meminta data yang sama, reverse proxy langsung memberikannya tanpa harus mengganggu server backend
- Routing / Port Forwarding : Mengarahkan berbagai domain atau URL ke aplikasi/port internal yang berbeda.
